Los datos son n (%) o mediana (RIC). Los porcentajes de asignación usan como denominador las evaluaciones de cada año de residencia.
Las comparaciones son entre años de residencia. Para las calificaciones, los años de residencia se comparan dentro de cada estrato de complejidad.
Las evaluaciones no son independientes (varias por residente); los valores de P son descriptivos. Las estimaciones ajustadas se muestran en la Tabla 4.
Valores de P: a prueba de χ²; b prueba de Kruskal-Wallis.
Abreviaturas: RIC, rango intercuartílico; R1–R5, residente de primer a quinto año.
